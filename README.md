# Own AI v0.1

A local-first browser AI built with vanilla HTML, CSS, JavaScript, and WebLLM.

## What makes it an actual AI?

The browser downloads an open language model and performs inference locally using WebGPU. The chat response is generated by the model rather than a hard-coded response system.

## Stack

- HTML
- CSS
- JavaScript
- WebLLM
- WebGPU
- GitHub Pages compatible

## Run locally

Because JavaScript modules should be served over HTTP rather than opened directly from `file://`, use a small local server.

### VS Code Live Server

1. Open the project folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.
5. Click **Load AI**.

A WebGPU-compatible browser is required.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

## Important

The first model load can be large because the model weights must be downloaded. Once cached by the browser, later startup can be faster.

## Rename the AI

Edit these two places:

- `index.html` — visible name and title.
- `app.js` — `SYSTEM_PROMPT` identity.
